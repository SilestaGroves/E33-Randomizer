## Download

- **E33Randomizer-v1.2.0-win-x64.zip** — unpack anywhere (not an admin folder) and run `E33Randomizer.exe`. Nothing else to install.
- **E33Randomizer-v1.2.0-win-x64-framework.zip** — a much smaller download for those who have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) installed.

This is the last version you need to download by hand.

## New: updates from inside the randomizer

- On startup the randomizer checks GitHub for a newer release and offers to install it. It only says something when there is an update; the check can be turned off at the bottom of the main window.
- The "Check for updates" button does the same on demand.
- The update downloads the same kind of zip you use (full or framework), checks it against the published SHA-256, replaces the program files and restarts the randomizer.
- Your settings, game folder, custom presets (`custom_1.json`, `custom_2.json`) and generated mods are kept.
- The version is shown in the window title.

The randomizer must be in a folder it can write to (not Program Files) to update itself; otherwise it offers the download link.
