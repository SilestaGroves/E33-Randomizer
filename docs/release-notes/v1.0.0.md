First release of this version of the randomizer, based on [jonathan-paugh/E33-Randomizer](https://github.com/jonathan-paugh/E33-Randomizer).

## Download

- **E33Randomizer-v1.0.0-win-x64.zip** — unpack anywhere (not an admin folder) and run `E33Randomizer.exe`. Nothing else to install.
- **E33Randomizer-v1.0.0-win-x64-framework.zip** — a much smaller download for those who have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) installed.

On first start, set the game folder at the bottom of the main window ("Find Steam install" or "Browse..."). Generated mods are then copied into `Sandfall\Content\Paks\~mods` automatically.

## New

- **Key item logic** (on by default): every key item is placed once, never in places that can't be revisited, and never behind a check that needs it, so all content stays obtainable. Fixed and prologue-only key items stay in their original places.
- **Enemy level scaling** (optional): encounters that get new enemies are fought at the level of the original encounter.
- **Spoiler log**: `spoiler_log.txt` next to the mod lists every changed encounter and check with readable names, and where every key item is. It warns when manual edits make a key item unobtainable.
- **Mod is copied into the game** automatically.
- Scripted story battles (Gustave vs Renoir, the final duel) and tutorial fights are no longer randomized, and neither are fights whose enemies drop merchant unlocks or Maelle's painter skills (their drops would be lost).

## Fixes

- Excluded enemies and items no longer give their chance to their neighbours in the list (one enemy could appear up to 24 times more often than intended).
- Broken enemies and items are never placed by randomization again.
- Generating several times in one session no longer crashes or leaks the previous result into the next one.
- Merchants no longer get duplicate items, which the game merged into one.
- Loading `encounters.txt` keeps battle flags (no escape, narrative battle, level), accepts Windows line endings and reports mistakes instead of applying half of the file.
- Reopening the custom placement and edit windows no longer crashes.
- Removing an excluded category no longer re-enables objects that are also in another excluded category; resetting to the default preset clears the lists.
- Extra copies of skill unlocks (e.g. an early gradient attack) are no longer placed in other checks.
- Packing waits for retoc and reports its errors.
- Save patching supports the current uesave format, keeps the original save as `.sav.bak`, and no longer changes anything else in the save.

Note: the same seed gives a different result than in the original version.
