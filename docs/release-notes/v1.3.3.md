## Fix: fights missing in v1.3.2

In v1.3.2, many fights didn't appear, among them the training dummy in Lumière and pairs of regular enemies.

In those fights, the first enemy was a replacement copy with the archetype of the enemy it replaced, and the copy's name ended in a number (for example `..._Regular_120`). The engine keeps such a final number apart from the rest of the name. The enemy table stored the copy's name that way, but the encounters named it as one piece of text. For the game these were two different names, so the encounter pointed at an enemy that didn't exist.

- Enemy names are now written into encounters the way the engine reads them.
- Copy names no longer end in a number.
- A test now checks that every enemy a fight names is a row of the enemy table, comparing names the way the game does.

Generate the mod again with this version. A save made with v1.3.2 is fine: the fights are back once the new mod is installed.

Updating: older versions offer this update on startup.
