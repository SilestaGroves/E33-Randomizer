## Tracker

A tracker for your run, in the style of the game's menus. Turn it on or off and open it in the **Misc** tab.

- **Key items:** all 21 progression items. Click one to mark it found. The **?** next to a key item that hasn't been found yet reveals where it is in this seed (a spoiler, so it's up to you).
- **Regions by act:** every place with items (836 in total), grouped by region, with a counter and a progress line per region. Areas you haven't reached yet are dimmed, finished ones are marked in gold.
- **The selected region:** its chests, merchants, dialogues and other rewards, to tick off as you take them. Places that need a key item you don't have yet say which one, in red. Pickups are named after what the original game had there, so you can find them with any map of the game.
- **Tracking from game saves:** each time the game saves, the tracker reads the newest Steam save and marks the key items in your inventory as found and the areas you've been to as visited. Chests and other places are ticked by hand: the save only stores them as internal object IDs that can't be matched to places without the game's level files.
- Progress is kept per seed, next to its spoiler log (`tracker_state.json` in the `rand_...` folder). **Another seed…** opens a different generated seed, and **Reset progress** (click twice) starts over.

The tracker follows the seed generated last; seeds generated with older versions have no tracker data, so generate the mod again to use it.
