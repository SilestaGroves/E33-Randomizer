## Download

- **E33Randomizer-v1.1.0-win-x64.zip** — unpack anywhere (not an admin folder) and run `E33Randomizer.exe`. Nothing else to install.
- **E33Randomizer-v1.1.0-win-x64-framework.zip** — a much smaller download for those who have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) installed.

## New

- **Giant enemies stay in arenas that fit them** (on by default): giants (Gargant, Glissando, the Paintress, Sirene, Visages, Tisseur, Serpenphare, the Giant Sapling) only appear in fights that had a giant in the original game, one per fight. Anywhere else they're rerolled with the same placement rules, so a boss is still replaced by a boss. Giants are the "Giant Enemies/Bosses" category in `Data/enemy_categories.json`, which can be extended.
- **Random encounter sizes only change enemy packs** (on by default): fights with a boss or a chromatic boss, and fights with only minibosses, keep their number of enemies. Packs, including packs where a miniboss comes with regular enemies, still change size. Enemy Onslaught is not affected.

## Save file scripts

- `ScriptsAndHelpers/save_file_patcher.py` and `enable_battle_challenge.py` work with the current uesave format (and the old one), find `uesave.exe` in the tools folder, and keep the original save as `.sav.bak`.
- The bundled uesave converts saves to JSON and back without changing anything else in the save.
