## Fix: crash after the Gommage with random starting cosmetics

With "Randomize starting cosmetics" on, Gustave started the game in a random outfit. The Gommage cutscene takes away his Lumière suit and dresses him in the expedition outfit, so with another starting outfit the game crashed right after the cutscene.

- Gustave always starts in his Lumière suit and Verso in his outfit without the armband (the story changes both). Their haircuts and all other starting outfits and haircuts are still random.
- Random starting cosmetics no longer pick excluded or broken items.

Generate the mod again with this version (it's copied into the game automatically if the game folder is set) and load a save from before the Gommage.

Updating: v1.2.0 offers this update on startup. From older versions, download **E33Randomizer-v1.2.1-win-x64.zip** once.
