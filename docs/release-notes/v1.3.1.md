## Fix: changed fights were at level 1

In v1.3.0, enemy level scaling fought every changed fight at level 1. The updated enemy data has no enemy levels, so every enemy counted as level 1. Bosses that replaced strong bosses were far too weak, and so were the mob packs.

Enemy levels now come from the game's enemy table. With "Scale enemy levels to the encounter", a changed fight is fought at the level of the original fight, in both directions: a weaker replacement is raised to that level, a stronger one is lowered.

## Skill randomizer fixes

The skill randomizer was an early version. The fixes are taken from the original randomizer:

- The "Randomize skills" checkbox turned item randomization on and off. It now turns on skill randomization.
- Skills are replaced by the custom placement rules. By default, each character keeps their own skills and gradient attacks stay on gradient nodes. Before, every node got any random skill, a random cost and a random visibility, and every tree got an extra connection.
- Nodes keep their unlock requirement (gradient unlocks, Monoco's feet, quest items).
- Monoco's tree is no longer damaged when it is written.
- Characters start with the skills that are now on their starting nodes, unlocked and equipped.
- Corrected skill file paths (the consumables pointed at files that don't exist).
- New options: keep Gustave's Overcharge, include cut content skills. "Reduce skill duplication" now keeps each skill to at most one node per tree.
