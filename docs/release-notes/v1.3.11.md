## Fixes

- **Skills drop from enemies** now works on its own: it no longer needs "Randomize skills". Without skill randomization every skill stays in its own tree and drops from enemies; with it, the shuffled skills do. Before, with "Randomize skills" off, the option silently did nothing.
- **Settings are kept between runs.** Changes on the tabs were lost when the randomizer was closed or restarted after an update, so a checked option could quietly be off at the next start. They're now saved when generating, when closing and before installing an update.

Check that a generated seed has the skill drops: its spoiler log has a "SKILLS DROPPED BY ENEMIES" section.
