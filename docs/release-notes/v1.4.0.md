## E33 Randomizer 1.4

### New in this version
- **Duplicate skill drops as a separate option.** Under "Skills drop from enemies" there's a new option, **Duplicate each skill on a second enemy** (on by default, as before). On: every skill drops from two different enemies, so a rare or missed enemy doesn't cost the skill. Off: every skill drops from one enemy only.

### Since 1.3.5, in short
- **Russian interface** with a language switch, **tooltips** for every setting, and a **Remove mod from game** button (1.3.6).
- **Tracker** in the style of the game's menus: key items with optional hints, every place with items by region, tracking from game saves (1.3.7). **Hotkeys** that work in the game and a **mini mode** overlay that never takes the focus or the cursor (1.3.8).
- **Skills drop from enemies:** every skill becomes an item that's learned the moment it drops (1.3.9, works without skill randomization since 1.3.11).
- **Random number of bosses in boss fights** (1.3.10).
- Settings are kept between runs and across updates (1.3.11).
